# Application-facing project summary

Systematic Trading Lab is an actively maintained open-source Python platform for reproducible quantitative research and tightly controlled paper execution. It records dataset identity, bounded experiment plans, qualification evidence, protected holdout access, runtime provenance, risk decisions, and paper-account observations as explicit evidence.

The project is maintained through focused pull requests with documented verification and safety boundaries. It includes substantial work on provenance, reproducibility, security controls, restart/recovery semantics, and deployment—not just strategy code.

External adoption should be described only with current public evidence. Do not infer usage from repository activity alone.
