# Data policy

Initial production research scope is adjusted regular-session daily OHLCV for SPY, QQQ, IWM, TLT, and GLD. The research-only intraday path permits offline `1m` and `5m` regular-session OHLCV, initially for SPY and QQQ. Preserve provider adapter, provider feed when present, request and actual ranges, retrieval time, raw hashes, schema and normalization versions, adjustment, calendar and timestamp policy, universe ID and fingerprint, validation evidence, missing and duplicate intervals, conflicts, quarantine counts, parent version, and final fingerprint.

Raw and normalized evidence is immutable. A dataset version ID binds the provider adapter, provider feed when present, sorted symbol set, timeframe, requested range, adjustment policy, schema, normalization and calendar versions, universe ID and fingerprint, raw artifact hash, and normalized-bar fingerprint. A changed snapshot for the same stable request and universe links to its latest cataloged parent; an exact repeat returns the existing version after its stored artifacts pass validation. Identical bars from different providers, feeds, requests, or universe definitions remain separate versions.

Normalize timestamps to UTC, reject non-finite or non-positive prices, negative volume, impossible OHLC, duplicates, and non-increasing order. Record missing daily sessions and intraday regular-session intervals from the XNYS exchange calendar rather than treating every weekday as a trading day or every day as 09:30–16:00. Intraday timestamps label bar opens; their duration comes from the manifest timeframe. Never infer a price or corporate action. Raw provider records are retained as canonical JSON Lines and normalized bars as deterministic Parquet; prices remain exact decimal strings in Parquet.

Cataloged experiment execution must use a Parquet predicate for the exact inclusive experiment timestamp range. It must verify catalog and stored manifest agreement, dataset and universe identity, range bounds, symbols, and complete XNYS sessions without loading the full normalized artifact or raw records. It must reject an empty, incomplete, mismatched, or out-of-range result. Holdout execution may begin this read only after consuming its stored authorization.

The read-only Alpaca adapter identifies itself as `alpaca-historical-v2`, records feed `iex`, requests `adjustment=all`, declares `provider-adjusted-all-v1`, uses the historical stock-bars API, and paginates with `next_page_token`. Repository timestamp ranges are inclusive bar labels; the adapter adds one day for daily bars or sets the intraday exclusive end to one duration after the last expected bar open. Synthetic fixtures declare `synthetic-no-actions-v1` and omit feed. Unadjusted data is rejected before acquisition until a reviewed local processor covers splits, dividends, symbol changes, and delistings.

Every import must use a versioned point-in-time universe. The fixed `liquid-etfs-v1` daily definition and `liquid-etfs-intraday-1m-v1` and `liquid-etfs-intraday-5m-v1` SPY/QQQ definitions record issuer-sourced inception intervals. Before provider access, the import must contain exactly the symbols with membership that covers the full requested range and matching timeframe. A request that crosses an inception date or omits an active member fails closed. Later definitions may add reviewed exit and re-entry intervals without changing sealed dataset provenance.
