# Code of Conduct

Systematic Trading Lab aims to keep technical collaboration focused, respectful, and evidence-based.

Participants are expected to:

- discuss ideas and code without personal attacks or harassment;
- give specific, actionable technical feedback;
- separate disagreement about evidence or design from judgments about contributors;
- respect privacy and never post credentials, private account data, or sensitive broker information;
- follow repository safety boundaries when discussing execution, risk, or security-sensitive behavior;
- accept maintainer decisions about project scope and protected controls even when proposing alternatives.

Harassment, threats, discriminatory abuse, deliberate disclosure of private information, or repeated disruptive behavior are not acceptable.

For ordinary project concerns, use the relevant issue or pull request. Security-sensitive reports should follow `SECURITY.md`. Conduct concerns that should not be handled publicly may be reported privately to the repository maintainer through an appropriate private GitHub channel.

Maintainers may edit or remove contributions or restrict participation when needed to protect contributors, users, or the project.
